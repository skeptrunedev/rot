# rot

Minimal blogging system written in Rust. CLI commands for scaffolding and adding content to a Rust-based blog.

## Goal

I have wanted to blog on my own corner of the internet for a long time. Primarily as a means of engaging more with communities I enjoy being a part of.

However, existing frameworks are either too no-code'y or require too much manual configuration to be usable. My goal with Rot is to fill the in-between. 

I am the ideal Rot user and will be completely ok with being its only user.

## Desired Functionality

- [ ] ability to use tailwind in templates
- [ ] ability to use tailwind and raw HTML in mdx
- [ ] blog frontmatter
  - require slug (id)
  - require date
  - require template name to use
  - standard field for og:title
  - standard field for og:image
  - standard field for og:description
  - all other fields optional
- [ ] store and fetch view counts on posts
- [ ] view posts by tag
- [ ] get list of posts ordered by recency, popularity, or alphabetical
  - [ ] support pagination
